# Proposal

## Why

用户在管理定时任务时，需要能够便捷地人工查看历史数据，并将任务的执行历史流（起止时间、耗时、退出码）以及本机的管理操作审计记录导出为通用的电子表格（CSV 格式），用于离线分析、审计汇报或故障排查。

## What Changes

- **新增日志导出功能**：在右侧日志/详情操作栏增加【导出日志】按钮。
- **智能范围识别**：
  - 当处于“运行历史”面板时，导出当前选中任务（或全局系统）的历史执行记录至 CSV。
  - 当处于“操作审计”面板时，导出当前选中任务（或全局管理操作）的审计记录至 CSV。
  - 当处于“详情”面板时，若选中任务则导出该任务的执行历史，否则导出全局操作审计。
- **Excel 友好导出**：生成的 CSV 文件带有 UTF-8 BOM 头，确保在简体中文 Windows 下双击 Excel 打开不发生乱码。
- **导出行为审计**：导出成功或失败时自动记录一条审计记录。

## Capabilities

### Modified Capabilities
- `task-log-stream`: 增加执行历史流与管理审计流导出至 CSV 文件的需求与规格。

## Impact

- **代码影响**：在 `task_eventlog.go` 与 `task_audit.go` 中增加 CSV 导出辅助函数；在 `main.go` 中增加【导出日志】按钮与对应的保存文件对话框交互。
- **依赖影响**：无额外外部依赖，使用 Go 标准库 `encoding/csv`。
