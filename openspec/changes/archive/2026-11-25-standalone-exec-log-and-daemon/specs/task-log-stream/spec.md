# Spec Delta

## REMOVED Requirements

### Requirement: 基于事件日志的任务执行历史查询
**Reason**: 用户明确要求不再读取 Windows 系统自带事件日志（`wevtutil`），改由本程序内置的独立后台采集器记录并读取本地按天落盘的运行历史文件。
**Migration**: 运行历史查询与导出统一迁移至独立按天日志文件 `logs/exec_YYYY-MM-DD.jsonl`（由后台轮询采集器维护）。

### Requirement: 系统调度历史通道状态检测与自愈
**Reason**: 不再依赖 Windows `Microsoft-Windows-TaskScheduler/Operational` 事件日志通道，无需检测或开启系统通道。
**Migration**: 由独立后台采集引擎（桌面内置 + `--daemon` 开机守护进程）替代系统通道完成执行留痕，界面原“启用历史”入口升级为“开机自启”管理入口。

## ADDED Requirements

### Requirement: 独立后台轮询采集全部定时任务执行日志并按天存储
系统 SHALL 通过后台定时轮询本机任务计划程序状态（不读取系统自带事件日志，不修改原有任务执行命令），捕获本机全部定时任务的运行启动、结束及上次运行时间与退出码变更，按自然天拆分持久化至 `logs/exec_YYYY-MM-DD.jsonl`。

#### Scenario: 捕获短耗时任务在轮询周期内执行完成
- **WHEN** 某定时任务在两次轮询间隔内启动并执行结束，导致 `LastRunTime` 发生变化
- **THEN** 采集器生成一条包含任务名称、开始时间、捕获完成时间、退出码、状态及执行命令的 JSON 记录，并追加写入当天的 `logs/exec_YYYY-MM-DD.jsonl`

#### Scenario: 捕获长耗时任务从运行中到结束的完整过程
- **WHEN** 某定时任务在一次轮询中状态变为“正在运行”，并在后续轮询中恢复为就绪或完成状态
- **THEN** 采集器先记录运行中快照，结束时使用同一 `InstanceID` 写入带估算耗时与最终退出码的完成记录

#### Scenario: 按自然天自动滚动分文件存储与状态基线防重
- **WHEN** 采集器跨自然天持续运行或进程重启后重新启动
- **THEN** 跨天后自动写入新日期命名的 `logs/exec_YYYY-MM-DD.jsonl`，并通过 `logs/monitor_state.json` 持久化基线避免重复记录已落盘的历史运行

### Requirement: 运行历史视图与导出完全基于独立本地日志
系统 SHALL 完全从本地按天日志文件 `logs/exec_YYYY-MM-DD.jsonl` 跨天倒序聚合读取任务运行历史（同一 `InstanceID` 自动合并保留最新状态），用于主界面“运行历史”展示及自定义条数的 CSV 导出。

#### Scenario: 选中任务或全局查看本地运行历史
- **WHEN** 用户在主界面切换至“运行历史”面板（无论是否选中某条任务，也无论该任务是自定义任务还是系统级任务）
- **THEN** 系统不调用 `wevtutil.exe`，直接从 `logs/exec_YYYY-MM-DD.jsonl` 跨天倒序聚合展示最新执行记录

#### Scenario: 导出独立运行历史为 CSV 文件
- **WHEN** 用户处于“运行历史”面板并点击“导出日志”，输入自定义条数或 `0`/`-1` 导出全部
- **THEN** 系统从本地按天日志文件中提取匹配记录并写入带 UTF-8 BOM 的 CSV 文件

### Requirement: 后台静默守护进程、系统托盘常驻与开机自启
系统 SHALL 支持 `--daemon` 无界面后台守护运行模式、桌面系统托盘最小化常驻及一键开机自启配置，并通过全局命名互斥锁避免守护进程与桌面端重复采集。

#### Scenario: 无界面后台守护进程与单实例防重复采集
- **WHEN** 系统以 `--daemon` 模式运行后台采集器，且用户同时打开桌面 GUI 界面
- **THEN** 守护进程持有全局采集互斥锁持续采集日志；桌面端检测到互斥锁已被占用时不再启动重复轮询，并在界面状态中显示后台采集运行中

#### Scenario: 桌面关闭最小化到系统托盘并支持唤醒与彻底退出
- **WHEN** 用户点击主窗口关闭按钮（X）
- **THEN** 窗口隐藏至右下角系统托盘并保持后台常驻；双击托盘图标或再次启动程序时恢复显示主窗口，通过托盘右键菜单“退出程序”可彻底退出

#### Scenario: 一键开启或关闭开机自启
- **WHEN** 用户在主界面或托盘右键菜单点击切换“开机自启”
- **THEN** 开启时注册 `SYSTEM / ONSTART` 后台守护计划任务（确保服务器重启无人登录时仍可采集）并配置当前用户登录托盘自启；关闭时清理上述计划任务与自启项
