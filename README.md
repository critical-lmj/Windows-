# Windows 定时任务管理器

面向 Windows Server 2008 R2 及以上系统的本地计划任务可视化管理工具。程序使用 Windows 自带的任务计划服务和 `schtasks.exe`，不需要联网，也不依赖浏览器或 WebView。

## 功能

- 查看、搜索和筛选本机计划任务（支持按状态、仅自定义任务、仅系统任务、仅已开审计快捷筛选）。
- 查看任务状态、日志审计状态、下次运行、上次运行、结果、创建时间、触发器、执行命令和任务位置。
- 运行、停止、启用、禁用、删除任务，以及按需手动开启/关闭单任务日志审计。
- 创建和修改单一程序操作、单一基础触发器的任务，向导默认勾选开启日志审计。
- 支持一次、每天、每周、每月、每月最后一天、重复间隔及关机事件触发任务。
- 新建任务默认使用 `NT AUTHORITY\\SYSTEM` 和最高权限运行，不依赖当前登录用户或远程桌面会话。
- **独立运行历史流（按天存储，不读系统事件日志）**：由内置/守护后台采集器零侵入轮询本机全部定时任务，自动捕获启动、完成、估算耗时与退出码，按天独立保存至 `logs/exec_YYYY-MM-DD.jsonl`（配合 `logs/monitor_state.json` 持久化状态基线防重）。
- **开机自启与后台常驻**：支持纯 Win32 系统托盘常驻（关闭窗口自动隐藏至托盘后台记录，右键可唤醒或彻底退出），以及一键开启/关闭“开机自启”（`SYSTEM / ONSTART` 无人登录后台守护进程 `--daemon` + 登录静默托盘 `--minimized`），通过全局命名互斥锁防止重复采集。
- **按月操作审计流**：将创建、修改、删除、启停、导入导出等管理操作异步写入按月拆分的本地日志 `logs/audit_YYYY-MM.jsonl`，支持跨月倒序聚合查看并兼容旧版 `audit.jsonl`。
- **自定义与系统级任务分类管理**：自动识别用户自定义任务与系统级任务，支持列表分类展示与快捷筛选；运行历史独立按天记录本机全部定时任务。
- **日志导出（CSV）**：支持将本地按天运行历史或按月操作审计导出为带 UTF-8 BOM 的 CSV 文件（Excel 打开不乱码）；导出前可自定义最大条数，输入 `0` 或 `-1` 表示导出全部（不限制数量）。
- 支持导出当前选中任务；未选中时导出当前筛选结果中的全部任务。
- 支持一键备份本机全部计划任务，并从 ZIP 备份包或单个 XML 文件批量导入恢复。
- 支持以管理员权限启动、操作超时隔离及调试日志，降低旧版服务器上的界面卡死风险。

## 运行环境

- Windows Server 2008 R2 Enterprise（64 位）或更高版本。
- 管理员权限；程序启动后会请求提升权限。
- 仅管理运行该程序的本机任务，不需要网络连接。

> 关闭远程桌面连接不会影响以 `SYSTEM` 身份运行的任务。服务器真正关机、断电或重启期间，任何本机程序都无法在关机状态下执行；可通过“错过计划时间后尽快运行”策略在下次开机后补执行。

## 构建

项目推荐使用 Go 1.20.14（Windows amd64）。

先在可联网的开发机执行：

```bat
prepare-portable-go.bat
```

该脚本会准备项目内的便携 Go 运行时和依赖缓存。随后执行：

```bat
build.bat
```

构建完成后会生成：

- `TaskSchedulerManager.exe`：桌面程序。
- `TaskSchedulerManager-debug.exe`：调试和自测版本。

## 使用

双击 `TaskSchedulerManager.exe` 启动。程序会尝试使用管理员权限重新启动；新建任务时默认写入：

```text
/ru SYSTEM /rl HIGHEST
```

因此任务可在用户注销或远程桌面断开后继续运行。执行程序建议使用本地绝对路径，例如 `E:\\scripts\\job.exe`；不要使用映射盘符。访问网络共享时，请使用 UNC 路径，并为计算机账户或 SYSTEM 账户配置相应权限。

### 独立日志采集、开机自启与托盘常驻

- **运行历史（按天独立留痕）**：不读取 Windows 系统自带事件日志。后台采集器默认每 10 秒轮询本机全部定时任务，并将每次运行留痕按天写入程序目录下的 `logs/exec_YYYY-MM-DD.jsonl`（例如 `logs/exec_2026-11-25.jsonl`）。未选中任务时可查看全局最新执行记录，选中任务时可查看该任务的历史记录。
- **操作审计（按月独立归档）**：切换至“操作审计”页签查看本工具执行的运维操作记录，按自然月保存于 `logs/audit_YYYY-MM.jsonl`。
- **开机自启与后台常驻**：
  - 点击右上角 **`开机自启`**（或在右下角托盘图标右键菜单点击），管理员权限下将注册 `SYSTEM / ONSTART` 后台守护计划任务（`\TaskSchedulerManager_LogDaemon`，以 `--daemon` 参数运行，服务器重启无人登录也能持续记录日志）及用户登录托盘任务（`--minimized`）。
  - 点击主窗口右上角 `X` 时，程序会自动最小化到系统托盘继续常驻；双击托盘图标或再次启动程序可恢复主窗口，右键托盘选择“退出程序”可彻底退出。
  - 守护进程与桌面端通过 Windows 全局命名互斥锁自动协同，不会重复轮询或写入重复记录。
- **导出日志与打开目录**：点击 **`打开日志`**（或右键托盘菜单“打开日志目录”）可直接打开本地 `logs\` 文件夹查看按天/按月原始日志文件；点击 **`导出日志`** 弹出条数设置窗口（默认 `200`，输入 `0` 或 `-1` 表示不限制数量导出全部），导出为带 UTF-8 BOM 的 CSV 文件。

### 导入、导出与备份

- **导出**：选中一条任务时导出该任务；没有选中任务时导出当前筛选结果。
- **备份全部**：导出本机全部计划任务，默认文件名为 `TaskBackup_日期时间.zip`。
- **导入**：支持本程序生成的 ZIP 备份包和 Windows 任务 XML 文件；ZIP 包内可包含多个任务。
- **同名任务**：逐条选择覆盖或跳过，不会静默修改已有任务。

备份包仅保存 Windows 原生任务 XML 和清单，不包含脚本、可执行程序、工作目录内容或历史执行数据。导入 SYSTEM 任务需要管理员权限。普通账户且依赖密码的任务无法从 XML 备份中恢复密码，需要在 Windows 任务计划程序中重新设置凭据。

## 自测

以管理员身份在命令行运行：

```bat
TaskSchedulerManager-debug.exe --self-test
```

自测会创建、读取、修改并删除带 `CodexScheduleSelfTest_` 前缀的临时任务，覆盖一次、每天、每周、每月、每月最后一天、重复间隔、关机事件及重命名。

## 目录说明

- `main.go`：应用主程序、Win32 界面与任务管理逻辑。
- `main_test.go`：任务参数、XML 解析、筛选及导出条数解析测试。
- `task_archive.go`：ZIP 备份包、任务 XML 导入导出与安全校验。
- `task_archive_test.go`：归档格式、批量导入导出和筛选导出范围测试。
- `task_audit.go`：本地按月操作审计流（`logs/audit_YYYY-MM.jsonl`）及单任务审计策略（`logs/audit_policy.json`）。
- `task_audit_test.go`：按月拆分、跨月聚合读取、任务分类及策略持久化测试。
- `task_exec_monitor.go`：独立后台定时轮询采集器、按天日志存储（`logs/exec_YYYY-MM-DD.jsonl`）及跨天去重聚合读取。
- `task_exec_monitor_test.go`：按天拆分、跨天去重及状态机 diff 单元测试。
- `autostart.go`：全局采集互斥锁、`--daemon` 无界面守护模式与开机自启（`ONSTART` / `ONLOGON` / 注册表兜底）。
- `autostart_test.go`：启动参数解析、自启命令及命名互斥锁单元测试。
- `tray.go`：纯 Win32 系统托盘常驻图标、右键菜单与单实例窗口唤醒。
- `task_eventlog.go`：运行历史数据结构与带 UTF-8 BOM 的 CSV 导出工具。
- `task_eventlog_test.go`：CSV 导出与解析兼容性单元测试。
- `openspec/`：功能需求规格与变更归档记录。
- `build.bat`：构建正式版和调试版。
- `prepare-portable-go.bat`：准备便携 Go 工具链。
- `权限和筛选说明.md`：权限、筛选范围说明。
- `go-task-scheduler-manager-项目介绍.md`：项目背景与设计介绍。
- `docs/Git上传清单与发布指南.md`：Git 源码提交流程与 Release 发布指引。

## 发布建议

源代码仓库只提交源码、构建脚本和文档。`.gitignore` 已排除 exe、日志与 `.runtime` 缓存。

面向用户发布时，将编译好的 exe（以及必要说明文件）作为 GitHub Release 或 GitLab Release 附件上传，不建议把二进制文件提交到 Git 历史。

## 注意事项

- 删除计划任务不可恢复。
- 复杂任务（多个触发器、多个操作或不受支持的高级设置）应使用 Windows“任务计划程序”原生界面编辑。
- 任务以 SYSTEM 运行时没有交互桌面，不能依赖弹窗、映射盘符或当前用户配置文件。
