# 定时任务导入、导出与备份设计

## 目标

为 Windows 定时任务管理器增加可离线使用的任务导入、批量导入、导出和全量备份能力，用于服务器任务迁移与故障恢复。

## 范围

- 导出：已选中任务时导出该任务；未选中任务时导出当前筛选结果中的全部任务。
- 备份：一键导出本机全部计划任务，文件名自动包含创建时间。
- 导入：支持本程序生成的 ZIP 备份包和单个 Windows 任务 XML 文件；ZIP 内的多个 XML 文件为批量导入。
- 冲突处理：目标服务器存在同名任务时，逐条由用户选择覆盖或跳过。
- 结果反馈：导入、导出、备份结束后显示成功、跳过、失败数量和逐项原因。

## 文件格式

使用 ZIP 容器，以保持 Windows 任务 XML 的完整定义：

- `manifest.json`：格式版本、导出时间、来源机器标识及任务清单。
- `tasks/<安全文件名>.xml`：每个计划任务的一份原生 XML。

任务 XML 来自 Windows 任务计划程序的 XML 导出接口；恢复时注册同一份 XML。备份包不包含任务调用的程序、脚本、工作目录内容或任何任务执行数据。

## 交互设计

主界面增加“导入”“导出”“备份全部”三个按钮。

- 导出前根据当前是否有选中项确定范围，并显示将导出的任务数量。
- 备份全部打开保存位置选择框，默认文件名为 `TaskBackup_yyyyMMdd_HHmmss.zip`。
- 导入先执行预检：解析文件、校验 XML、读取任务名称与执行命令、识别同名冲突；之后按顺序导入。
- 每次出现同名任务时，弹出当前任务的“覆盖 / 跳过”选择，不进行静默覆盖。

## 权限与兼容性

- 任务 XML 会尽量按原定义恢复；由本程序创建的 SYSTEM / HIGHEST 任务可完整迁移。
- 导入 SYSTEM 任务要求程序已提升为管理员；未提升时不写入并显示明确原因。
- 依赖普通用户密码的任务无法从 XML 中恢复密码，导入结果需提示用户在 Windows 任务计划程序中重新设置凭据。
- 操作兼容 Windows Server 2008 R2，且不依赖联网服务。

## 错误处理

- ZIP 损坏、缺少清单、非法 XML 或不支持的压缩路径：预检阶段拒绝导入，不修改任何任务。
- 单个任务导入失败：记录失败原因，继续处理余下任务。
- 导入、导出和备份均在后台执行，期间禁用对应按钮，避免界面卡死或重复操作。

## 验收标准

1. 可导出单个已选中任务，以及当前筛选结果中的多个任务。
2. 可一键生成包含本机所有任务的带时间戳 ZIP 备份包。
3. 可从 ZIP 与单个 XML 导入任务；同名任务逐条询问覆盖或跳过。
4. 对由本程序创建的 SYSTEM / HIGHEST 任务，导出后再导入，XML 中的执行账户与最高权限保持一致。
5. 全量测试覆盖 ZIP 清单读写、路径安全校验、XML 任务名解析、同名决策和导入结果汇总。
