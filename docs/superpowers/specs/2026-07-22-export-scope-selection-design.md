# 导出范围与选择状态

## 目标

修复任务列表刷新或筛选后自动选择第一项，导致“导出”总是只导出一个任务的问题。

## 确认的交互规则

- 刷新、搜索或切换筛选条件后，列表不自动选择任何任务。
- 用户未主动选择任务时，点击“导出”会将当前筛选结果中的全部任务写入一个 ZIP 包。
- 用户主动选择某一任务时，点击“导出”只导出该任务。
- “备份全部”不受筛选或选择状态影响，仍备份全部本机任务。

## 实现边界

- 不新增按钮，不改变导入、备份文件格式或任务 XML 读取方式。
- 保留现有单项导出能力。
- 任务操作按钮在无选中项时保持不可用；详情面板显示为空。

## 验证

- 单元测试覆盖：无选中项导出筛选集合；有选中项只导出该项；列表渲染不隐式选择首项。
