# 新建与修改任务的名称重复验证

## 目标

在新建任务和修改任务改名时，于界面提交前明确提示同名冲突，同时保留保存阶段的系统级验证。

## 确认的交互规则

- 点击“创建任务”或“保存修改”时，先将输入名称按现有规则规范化。
- 新建任务：当前已加载任务列表中存在同名完整路径时，阻止保存，提示“任务名已存在”，并将焦点置于任务名称输入框。
- 修改任务：名称未变化时允许保存；改名为其他已存在任务时阻止保存并提示。
- 比较使用 Windows 任务计划程序路径语义：忽略大小写，并将不带前导反斜杠的输入视为同一路径。
- 名称格式不合法时沿用现有格式校验提示，不执行重复判断。

## 一致性与边界

- 界面检查只使用已加载的 `allTasks` 快照，不调用外部命令，避免冻结 UI。
- 保存辅助进程保留现有 `taskExists` 系统级检查，以处理列表过期或其他进程同时创建任务的情况。
- 不修改任务创建参数、SYSTEM 权限、导入导出逻辑或任务名称规范化规则。

## 验证

- 测试新建同名、修改保持原名、修改改为其他已有任务名和大小写不同名称。
- 测试非法名称优先返回格式错误。
- 运行完整 Go 测试并构建 GUI 与调试版 EXE。
